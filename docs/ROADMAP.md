# 产品路线

## 当前 MVP

当前目标是完成五条闭环：灵感到第一章、作者写作 + Observer、Writer + Observer、卡文推演、跨电脑恢复。实现范围以 `PRODUCT_REQUIREMENTS_V0.2.md` 第 20～21 节为验收基线。

## 紧接 MVP 的增强

- 已有长篇正文的分批接管、分卷分章识别和反向建库；
- 更精确的非重叠三方自动合并与逐段接受；
- 正典候选的自动抽取、冲突影响图和确认工作流；
- Navigator 对作者回答的多轮高影响问题收敛；
- 多个运行中 Agent 之间的实时双向消息、排队与可视化消息总线（MVP 已支持作者显式把阻断评论续接给原 Writer）；
- 本地数据库/全文索引的性能层，以及大仓库增量重建；
- Windows 支持、签名安装包和自动更新。

## 后续产品版图

- 来源化资料研究、事实卡和版权/引用管理；
- 全书结构修订、伏笔回收矩阵和语言校对；
- 存稿、连载日历、发布准备和经授权的平台连接；
- 读者反馈导入、聚类和叙事承诺分析；
- 编辑、校对、共同作者与测试读者协作；
- 多语种、有声、漫画和短剧等 IP 延展。

无论能力如何扩展，修改已确认核心正典、删除/移动大量文件、Git 写操作、上传未公开全文和对外发布都继续保留显式授权门禁。
