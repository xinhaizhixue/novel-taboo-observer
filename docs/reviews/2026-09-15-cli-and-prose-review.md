# 0.3.1：CLI 发现、审阅与选择控件

## 改动

- 在桌面精简 PATH 下搜索用户安装目录、NVM、Volta、asdf、Homebrew；子进程补回可执行文件所在目录，避免 Node shebang 无法启动。
- 注册 TraeX；保留 Codex 桌面客户端的路径优先级。Claude 区分未登录与认证检测失败，支持结构化输出与失败结果。
- Observer 选择保存到设置，手动、自动及 Writer 后审阅统一使用选择；不可用时不偷偷切换。
- 两次独立调用：首次在独立目录读正文并保存逐章理解、台词依据和卡顿；第二次结合上下文逐条处理疑点，再审查六个维度。缺失初读证据、虚构引用、漏处理疑点不算完成。
- 选择控件使用统一的面板内展开列表，支持箭头键、Home/End、Escape 和焦点恢复。窄面板上下排列，避免名称被挤压或菜单覆盖输入。

## 检验

- 原有与新增完整回归：128 项通过；后续结构化输出/失败处理增补测试通过。
- 模拟 Finder PATH=/usr/bin:/bin:/usr/sbin:/sbin，真实 Claude 与 TraeX 检测、认证通过。
- Claude 实际模型调用：初期两轮均漏报过度省略（4/5），加入逐条台词依据检查后同组 5/5，通过三个问题片段及两个合理省略对照。前两轮失败记录保留在本地，没有用模拟结果替代真实检验。
- 五个样本是开发回归集，并非独立盲测集或总体检出率；不能据此保证不再漏报。
